# Calculatrice Odoo

Module Odoo 19 permettant d'effectuer différents calculs.

## Fonctionnalités

- Addition
- Soustraction
- Multiplication
- Division
- Modulo
- PGCD
- Recherche globale
- Association de calculs avec des contacts
- Smart button "Calculs" sur les contacts
- Impression historique de calcul

## Version

3.1.0

## Compatibilité

- Odoo 19.0
